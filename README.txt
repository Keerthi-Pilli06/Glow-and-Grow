Glow & Grow — Haircare Website

Project Description:
A modern interactive haircare website concept focused on shine, smoothness and healthy-looking hair.

Technologies Used:
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome

Project Structure:
- index.html: Home page with sections for hero, products, routine, quiz, about, contact and footer.
- login.html: Frontend login demo page with validation.
- register.html: Frontend registration demo page with validation.
- css/style.css: Main styling for the complete website.
- js/script.js: JavaScript for navigation, cart, toast, quiz, animations and form validation.
- images/: Folder containing hero and product images used throughout the website.

How to Run:
1. Open the Glow-And-Grow folder in VS Code.
2. Open index.html.
3. Right-click index.html.
4. Select "Open with Live Server".
5. The website will open in the browser.

No backend or database is required.
